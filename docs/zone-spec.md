# 通常時特殊ZONE仕様（設定6のみ）

## 適用範囲・優先順位
- 対象: `src/slot-v2/cpp/` の**設定6**。設定1〜5・7には変更を加えない。
- 本書は「ペンギンZONE」「キングダムZONE（過去の名称: ペンギン王国ZONE）」の通常時用仕様を扱う。
- 既存設定6の通常時基礎確率（天井を含まない）: CZ **1/1150**、通常当たり（ボーナス）**1/1700**、AT直撃 **1/2650**。変更禁止。
- 既存通常抽選の優先順位 **AT > ボーナス > CZ** を変更しない。新規ZONE突入抽選との相対優先順位は未確定（Q8）。
- AT中の特殊ZONE（下位1/500・中位1/450・上位1/400）は**別系統**であり、今回の通常時ZONEとは混ぜない。
- 設定6の機械割114%は**目標値**であり、今回の実装で達成したと扱わない。

- 成立役ごとにポイントを加算し、ZONEごとの上限で打ち止め。
- 報酬は**最終到達ポイントに対応する最上位1段階のみ**。下位報酬の累積付与禁止。

- `None` など、ポイント表に定義のない内部フラグの扱いは推測しない。

## 最終ポイント別報酬【確定】
| 到達pt（上限側の段階を1つ選ぶ） | 報酬 |
|---|---|
| 5pt以上 | 表示G数 +10G |
| 10pt以上 | 表示G数 +20G |
| 20pt以上 | 表示G数 +30G |
| 30pt以上 | 表示G数 +50G |
| 40pt以上 | 表示G数 +100G |
| 50pt以上 | 表示G数 +200G |
| 70pt以上 | 当たり濃厚：**ボーナス2 : AT1** |

- 70/80/100ptの報酬はキングダムZONE専用（ペンギンZONEは50pt上限）。
- 5〜50ptの**表示G数**は現行コードの `normal_state::State::display_games` を指す。加算関数は `normal_state::addDisplayGames`。 `actual_games` へ直接加算しない（Q2のコード照合結果）。
- 0〜4ptの場合の無報酬処理は、5G蓄積ならハズレ・1枚役のみでも5ptに達する。ただし既存役以外の異常系を含む実装時には改めて確認する。
