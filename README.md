# S-ChatGPT

> **Current development (2026-09-23): setting 6 only.** See [the approved setting-6 checkpoint](docs/setting6-checkpoint.md) for current normal/AT odds and implementation status. Historical calibrated results and odds elsewhere in this README are not current setting-6 measurements.

個人用パチスロ試作。計算・抽選・状態遷移は C++、ブラウザ側は WebAssembly 経由で利用する。

## 現在の実装

- 通常時の乱数空間: `2^27 = 134,217,728`
- 設定6の公開目標値: CZ 約1/350、通常ボーナス 約1/400、AT 約1/500（いずれも救済・昇格・天井を含む最終合算値）
- 通常モード: 通常A / 通常B / 天国 / 超天国 / 特殊
- 通常モード基本比率: 45% / 35% / 15% / 5%。特殊は超天国の20〜30G帯の10%移行判定から派生
- 通常時特殊契機: 1/8192 = ストック付き中位AT、1/32768 = 上位AT、1/134217728 = フリーズ + 上位ATストック
- CZ: 10G、基礎1/100で通常ボーナス。役別補正用フックあり。3スルーで通常ボーナス
- 通常ボーナス: 50枚。10%でストック。終了後1%で80枚エピソードへ昇格
- エピソード: 天国 / 超天国ATテーブルから直接当選可能。1/3で中位AT抽選
- AT: 下位 / 中位 / 上位
- 純増: 下位・中位 6枚/G、上位 12枚/G
- 初期G数: 20〜200G中心、300G薄め、平均50G
- AT内部テーブル: 通常 / 天国 / 超天国 / 特化 × 各5パターン
- ATテーブル/パターン移行: 約1/99
- 下位AT基準: 通常当たり1/200、転落1/400、追加G1/300、特化1/700、エピソード1/1000、上位特化1/5000
- 天国は通常当たり寄り、超天国は追加G寄り、特化は通常当たり/追加Gを抑えて特化寄り
- エピソードは天国/超天国限定、上位特化は特化テーブル限定
- 中位転落は下位 or 継続。上位転落は終了 or 継続
- 上位終了後: 64G引き戻し演出、期待度20%、成功で上位AT再開
- 通常特化: 5G、各G 1/2。成功時95%追加G / 5%通常ボーナス。平均+100Gを狙う
- 上位特化: 3G×4操作のプリセット式。1G内で当たり位置は最大1箇所。短命〜100連級まで含む広い分布で平均16連・平均+700Gを狙う
- AT当たり時ストック: 10%。AT終了時に発動し、初期G数は共通抽選、ATテーブル/パターンは再抽選
- 有利区間跨ぎ: ストックを複数回抽選として持ち越さず、0/1/3/5個以上の閾値で優遇パラメータを変えた「1回の次区間抽選」へ圧縮\n- 有利区間差枚: 6.5号機型として区間開始時を0基準に管理し、現在差枚が+2400枚へ到達した時に区間切断。区間内最低差枚は判定基準にしない

## 暫定調整値

下記は骨格を動かすための暫定値。シミュレーションで設定6の最終合算へ収束させながら調整する。

- 素CZ / 素ボーナス / 素AT直撃率
- 通常ボーナスからATへの演出成功率
- CZの成立役別補正とAT直撃率
- 通常天井到達時の「CZ以上」振り分け
- 中位/上位の転落判定内訳
- AT各テーブル・各パターンの厳密な確率倍率
- 有利区間跨ぎ時の0/1/3/5ストック優遇パラメータ本体
- 上位特化4096系プリセットの最終重み

## Native build / simulation

```bash
cmake -S . -B build
cmake --build build -j
./build/slot_sim 1000000
```

## WebAssembly build

Emscripten (`emcmake`, `em++`) が必要。

```bash
emcmake cmake -S . -B build-wasm
cmake --build build-wasm -j
cp build-wasm/slot.js build-wasm/slot.wasm web/
```

その後 `web/` をHTTPサーバーから開く。
